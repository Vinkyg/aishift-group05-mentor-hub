# Работа менторов / модераторов

**Михаил — модератор. Антон Винидиктов — помощник модератора.** В материалах нет отдельного утверждённого состава приглашённых менторов и распределения ответственности между ними.

Этот репозиторий — рабочее пространство сопровождения конкретной группы «Организация производства». Он не является официальной методичкой программы.

- [Трекер проектов и вопросов](tracker.md).
- [Сценарий следующей проверки прогресса](next-session.md).
- [Состав группы](../participants/README.md).

Порядок разбора: бизнес-проблема → текущий процесс → причины → изменение работы → роль ИИ → метрики → проверка → эффект.

Сначала задаём вопросы и помогаем участнику выбрать решение. Факты, гипотезы и рекомендации отмечаем отдельно. Поля ответственного и срока заполняем только после явной договорённости.
