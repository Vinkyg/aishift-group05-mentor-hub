## Статус материалов

Карточки содержат ситуацию, цель, процесс, вход и выход, гипотезу роли ИИ, метрики и вопросы. Где фактов недостаточно, стоят явные отметки. Схемы — редакционные обобщения для проверки участниками; численные ориентиры не являются подтверждёнными результатами.

Встреча с новым участником Евгением Федотовым учтена. Текущая постановка «Практики» дополнена подготовкой и проверкой ПД до РНС; ДЗ Игоря про ЭДО выделено отдельно. У Дмитрия разделены учебный пилот и более широкий исходный запрос.

Ответственные за подготовку следующих артефактов и сроки не назначены: договорённости ещё нужно зафиксировать.

## Доступ и публикация

Репозиторий предназначен для приватной работы менторов. Приглашённые пользователи пока не определены. GitHub Pages и автоматическая публикация не настроены.

Внутри есть рабочие расшифровки с именами и бизнес-контекстом. Закрытый фрагмент предыдущей записи исключён. Сырые аудиозаписи, контакты и материалы других групп не включены. Доступ к основным материалам не требует Google Диска.
